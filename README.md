# Spinner Selection App
## Project Overview
A simple Android app developed using Kotlin and XML for the Veda Technology Android Development Track (Day 16). It uses a Spinner to allow users to select a city from a dropdown list and displays the selected item.
## Technologies Used
- Kotlin
- XML Layouts
- Android Studio
## Features
- Spinner with a list of Indian cities
- Show Selection button
- Displays the selected city
## How to Run
1. Clone the repository. 2. Open in Android Studio. 3. Sync Gradle. 4. Run the app.
## Outcome
The application successfully displays the selected city from the Spinner dropdown.
